## 二、如果找不到原脚本（不确定是哪个）

没关系，重建一个新的同样能用：

1. 脚本编辑器左侧「新建文档共享脚本」，粘贴对应文件全部内容并保存。
2. 点脚本名旁「⋯」→「复制 webhook 链接」，发给我。
3. 我把新链接更新进仓库密钥（深圳 `WPS_AIRSCRIPT_WEBHOOK` / 赛迪斯 `WPS_AIRSCRIPT_WEBHOOK_SAIDIS`），其余不用你管。

## 三、脚本能力一览（粘贴即生效，无需配置）

| 触发 | 效果 |
|---|---|
| 系统出库/入库一笔 | 对应子表追加一行：日期、领取人（入库显示「入库」）、发放人（陈利冠），各商品填到自己的「发放/库存」列，库存自动累计；入库行整行标黄 |
| 系统删除一条记录 | 金山对应行自动删除，并重算下游库存 |
| 库存页**新增货品** | 自动识别系列 → 在对应子表插入「发放/库存」两列（自动放表头） |
| 库存页**删除货品** | 自动删除该货品对应的「库存」「发放」两列（含全部历史数据，不可恢复，前端已强确认） |
| 货品改名 | 自动配对：同子表同列位置视为改名，不删旧列不建新列 |
| 有备注的商品（如袋子） | 不会建列（产品目录里 wps 字段为空时跳过） |

## 备注

- 若贴完脚本后测试发现库存对不上 / 列没对上，把现象发我即可（脚本内有完整的读表/查找/清理分支，可远程排查）。
