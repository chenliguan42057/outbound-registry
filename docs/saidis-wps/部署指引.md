## 二、本次升级要做的一步（两个文档都要粘，约 1 分钟）

**新功能**：库存页面出现「🗑 删除」按钮；新增货品 → 金山对应子表自动多出「发放/库存」两列；删除货品 → 那一列（含全部历史发放/库存记录）自动删掉。

### 深圳细胞文档

1. 打开深圳细胞金山台账文档（原「鹿茸精华液.ksheet」，你日常在用那个）。
2. 「效率」→「高级开发」→「AirScript 脚本编辑器」。
3. 点开你**之前创建的那个脚本**（webhook 就是仓库密钥 `WPS_AIRSCRIPT_WEBHOOK` 指向的那个，别动它）。
4. 右侧代码区 **Ctrl+A → 删除全部**，然后把本目录 **`airscript_shenzhen.js`** 全选复制粘贴进去，**Ctrl+S 保存**。

### 赛迪斯文档

1. 打开 `https://www.kdocs.cn/l/cvuTJ0W1GSxl`（赛迪斯：小鹿产品登记）。
2. 同样进入脚本编辑器，点开 webhook 为 `…/script/V2-7Mj0bkvxlRW0lk3LE2edZJ/sync_task` 的那个脚本。
3. **Ctrl+A → 删除全部** → 粘贴本目录 **`airscript_saidis.js`** → **Ctrl+S 保存**。

## 四、脚本能力一览（粘好即生效，无需配置）

| 触发 | 效果 |
|---|---|
| 系统出库/入库一笔 | 对应子表追加一行：日期、领取人（入库显示「入库」）、发放人（陈利冠），各商品填到自己的「发放/库存」列，库存自动累计；入库行整行标黄 |
| 系统删除一条记录 | 金山对应行自动删除，并重算下游库存 |
| 库存页**新增货品** | 自动识别系列 → 在对应子表插入「发放/库存」两列（自动放表头） |
| 库存页**删除货品** | 自动删除该货品对应的「库存」「发放」两列（含全部历史数据，不可恢复，前端已强确认） |
| 货品改名 | 自动配对：同子表同列位置视为改名，不删旧列不建新列 |
| 有备注的商品（如袋子） | 不会建列（产品目录里 wps 字段为空时跳过） |

## 备注

- 若贴完脚本后测试发现库存对不上 / 列没对上，把现象发我即可（脚本内有完整的读表/查找/清理分支，可远程排查）。
- 日常改逻辑时两份脚本都要同步改（深圳源 `lurong-sync/airscript_append.js` 与赛迪斯副本），改完重新粘贴一次即可。
